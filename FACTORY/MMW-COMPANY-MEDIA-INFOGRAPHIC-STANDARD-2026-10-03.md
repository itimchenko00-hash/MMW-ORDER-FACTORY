# MMW-COMPANY — MEDIA & INFOGRAPHIC STANDARD

Дата: 2026-10-03

## Правило визуальной точности

Для каждого проектного продукта MMW-COMPANY каждый раскрываемый информационный блок получает отдельный локальный медиа-элемент из соответствующего проектного набора. Изображение выбирается по смыслу текста блока и не используется повторно внутри страницы.

## Правило инфографики

Каждый из восьми проектных блоков получает собственную инфографическую композицию. Инфографика должна объяснять смысл конкретного блока, а не быть декоративным повторением общей схемы проекта. Внутри одного проекта формы, композиции и визуальные метафоры не повторяются.

## Правило проекта

- 1 hero-изображение проекта;
- 8 отдельных изображений для 8 информационных блоков;
- 8 отдельных инфографических композиций;
- изображения только из локального проектного набора;
- изображения разных проектов не смешиваются;
- отсутствующие данные не компенсируются вымышленными визуальными фактами;
- визуальная система проекта сохраняет собственный цвет, ритм и характер внутри единого DNA MMW-COMPANY.

## Принцип качества

Фотография отвечает на вопрос «что это выглядит в реальности?», инфографика — «как это устроено?». Эти два слоя дополняют текст и не дублируют друг друга.

## Принцип замены

При последующей редакции визуального слоя соответствующий элемент заменяется. Старые варианты не наслаиваются.
