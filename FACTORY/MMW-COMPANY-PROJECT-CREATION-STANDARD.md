# MMW-COMPANY FACTORY — PROJECT CREATION STANDARD
Version 2026-10-03

This is the mandatory base for MMW-COMPANY and every future project.

1. PROTECTION
FROZEN / CONSERVED / ARCHIVE sources are read-only. Never move, rename, overwrite or delete them. Work only from copies.

2. CANONICALITY
One source owns one function. Replace canonical content; never overlay duplicate blocks, renderers, handlers, media maps or styles.

3. BUSINESS STRUCTURE
Identity → Product → Market → Delivery Model → Economics → Team → Risk Control → Next Step.

4. CORPORATE DNA
Every project belongs to MMW-COMPANY and inherits commercial clarity, navigation, hierarchy, responsive discipline and interaction quality.

5. PROJECT UNIQUENESS
Every project defines its own color palette, infographic language, visual effects and card/detail interaction while remaining recognizably MMW.

6. MEDIA
Every company/project page has a permanent local media pack. Semantic blocks use project-owned photographs or infographics. No runtime image generation. External photographs may enter only through an explicit licensed/download-permitted acquisition process, then become local project assets.

7. ECONOMICS
Land, design, permits, construction, utilities, landscaping, marketing, sales, reserve, unit cost, sale price, revenue, investor income, MMW income, break-even, ROI and payback are modeled from explicit inputs.

8. STATUS
Concept projects must be clearly labelled as concepts and never presented as launched objects without verified evidence.

9. INTERACTION
A card contains one idea. Opening a card reveals process and result without duplicating the entire card content.

10. QA GATE
Before publication: syntax, routes, assets, media ownership, image existence, interactions, responsive layout, duplicate detection and runtime health must pass.

11. FUTURE PROJECT GATE
No new project enters the portfolio until the same standard, media map, visual identity and QA gate are complete.
