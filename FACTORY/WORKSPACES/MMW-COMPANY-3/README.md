# MMW-COMPANY/3 — WORKING

## Назначение
Чистое рабочее пространство для новой MMW-COMPANY.

## Состояние
- **WORKING** — единственная активная зона разработки.
- Предыдущие реализации сайта, медиаслои и проектный runtime-код из этого рабочего пространства удалены.
- Замороженные эталоны и накопленный опыт Factory не изменяются и используются только как источник проверенных принципов и уроков.

## Правило старта
Работа начинается с чистого листа:
**Конституция → Standard → методологический контур → архитектура → контент → визуальная система → реализация → QA → release.**

## Запреты
- не переносить старую реализацию сайта;
- не подключать внешний runtime-media;
- не смешивать company-level и project-level контент;
- не начинать визуальную имплементацию до фиксации архитектуры;
- не продвигать состояние дальше при провале QA-gate.

## Источник опыта
Используется совокупный опыт Factory по MMW-COMPANY, ALADIN RESIDENCE, NEXUS WORK, NEXUS LOGISTICS, CARPATHIA ECO LODGE, AGROHUB, ENERGY PARK и другим завершённым работам.
