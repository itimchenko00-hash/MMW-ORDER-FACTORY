# MMW-COMPANY/3 — Visual & Interaction System

## Brand
Primary brand direction: premium light emerald.
Core palette:
- Deep Emerald Ink #06251F — brand authority, system layer.
- Emerald #58D6B0 — primary accent and interaction state.
- Soft Emerald #8EE8CB — secondary highlight.
- Mint #DDF7EE — surfaces and calm emphasis.
- Mist #F3FBF7 — process backgrounds.
- Ivory #FAFCF8 — primary canvas.
- Warm Gold #C6A85A — selective premium/commercial accent.

The emerald family is the visual identity. Gold is an accent only, never a competing brand color.

## Section-specific visual languages
- Hero: emerald field + orbital opportunity model.
- Scope: mint interface + sector switcher.
- Method: deep emerald process console + stage viewer.
- Audience: warm ivory/gold decision surface.
- International: pale emerald principle matrix.
- Portfolio: clean ivory project gallery with semantic project photography.
- New projects: mist catalog explorer with live search and expandable cards.
- System: deep emerald manifesto layer.
- Contact: light emerald conversion surface.

## Interaction rule
Every interactive element must solve a user task. No interaction is added only for visual movement.

### Unique mechanics
1. Hero — orbit control: jumps to the working method.
2. Scope — sector switcher: changes the active business domain and explanation.
3. Method — stage navigator: changes stage number, image and detailed explanation.
4. Audience — role selector: changes the problem and MMW response.
5. International — principle matrix: reveals practical meaning of the selected principle.
6. Portfolio — semantic filter: narrows real projects by domain.
7. New projects — live search + expandable card: helps discover or inspect a possible direction.
8. System — linear model: communicates the invariant development discipline; no duplicate interaction.
9. Contact — mail action + copy action: direct conversion utility.

## Commercial cleanliness
- No repeated primary CTA within the same section.
- No decorative card interaction without informational consequence.
- Concepts remain explicitly concepts.
- No invented project economics or launch claims.
- Company-level positioning stays separate from project-level detail.
- Project images are local repository assets and are assigned semantically.

## Responsive rule
Desktop uses composition and comparison; mobile collapses each interaction into a single focused control without losing information.
