# ЧИСТЫЙ ДОМ

Изолированный проект Factory для будущего сайта клининговой компании.

## Статус

ARCHITECTURE / FOUNDATION

## Правила

- Проект изолирован внутри Factory.
- Основная ветка `main` не изменяется проектными экспериментами.
- Работа выполняется в отдельных WORK-ветках.
- Защищённые и опубликованные проекты не изменяются без явной команды на публикацию.
- Старые версии не удаляются: перед заменой сохраняются в КОРЗИНА.
- Один источник истины для каждого элемента.
- Не добавлять новые слои до понимания существующей архитектуры.
- Все изменения должны быть обратимыми.

## План архитектуры

Будущая структура будет собираться по слоям:

1. `01-BRAND` — бренд и визуальная система.
2. `02-CONTENT` — тексты, услуги, предложения и доказательства.
3. `03-PAGES` — структура страниц сайта.
4. `04-COMPONENTS` — переиспользуемые интерфейсные компоненты.
5. `05-DATA` — цены, услуги, зоны обслуживания, контакты и бизнес-данные.
6. `06-FUNCTIONS` — заявки, расчёт стоимости, связь и другие функции.
7. `07-MEDIA` — фотографии, видео и графика.
8. `08-DOCS` — ТЗ, решения и документация.
9. `09-WORK` — текущие рабочие материалы и эксперименты.
10. `10-ARCHIVE` — внутренний архив проекта.

Эта структура является фундаментом проекта и не означает автоматического создания всех слоёв до появления реальной необходимости.
