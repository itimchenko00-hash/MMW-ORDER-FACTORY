# CHISTIY DOM — SITE ARCHITECTURE

## Site model

01 HERO — promise + primary call to action
02 POSITIONING — what the company actually solves
03 SERVICE SYSTEM — service matrix
04 B2B — business cleaning model
05 PRICE MATRIX — working prices with confirmation status
06 NETWORK — Kolomyia / Snyatyn / regional coverage
07 PROCESS — request → assessment → execution → result
08 CONTACT — phone-first conversion block

## Navigation

Послуги / B2B / Ціни / Географія / Контакти

## Conversion logic

Traffic → service recognition → trust → scope → price orientation → contact.

## Visual system

MMW-COMPANY-inspired dark interface, strong typography, thin technical borders, lime accent, dense information blocks, restrained animation, mobile-first responsive behavior.

## Architecture rule

The site draft is isolated in `PROJECTS/CHISTIY-DOM` and currently lives on `WORK/CHISTIY-DOM-SITE-2026-09-07`. It is not promoted to `main`, Render or any external project until explicitly commanded.
