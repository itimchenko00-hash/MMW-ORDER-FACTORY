## Decision

## Sources currently researched
Pexels — commercial website use is permitted under its license, but current terms prohibit bulk/large-scale/systematic copying without permission. Therefore assets must be individually selected/acquired and registered rather than scraped as a 350-file dump.

Unsplash — commercial use is generally permitted under the Unsplash License; API integrations have additional hotlinking, attribution and download-event requirements. If API use is chosen, those rules must be implemented.
