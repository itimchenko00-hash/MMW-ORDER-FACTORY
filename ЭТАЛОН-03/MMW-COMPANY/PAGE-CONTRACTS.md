## Universal page contract

Every canonical page must define:

- `PAGE_ID`
- `ROUTE`
- `PURPOSE`
- `AUDIENCE`
- `PRIMARY_CTA`
- `SECONDARY_CTA`
- `SECTIONS`
- `CONTENT_SOURCE`
- `MEDIA_SOURCE`
- `CSS_SCOPE`
- `JS_SCOPE`
- `SEO`
- `ACCESSIBILITY`
- `ANALYTICS`

No page is considered canonical if any of these are implicitly supplied by a historical runtime hook.
