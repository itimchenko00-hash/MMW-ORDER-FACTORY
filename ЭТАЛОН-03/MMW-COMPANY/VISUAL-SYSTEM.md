## Status
WORKING — visual construction started from the canonical Etalon 03 architecture.

## Scope
Visual layer only. Page contracts, routes, project boundaries and business content architecture remain unchanged.

## Principles
- One MMW-COMPANY visual language.
- Editorial / architectural / premium technical character.
- Dark neutral base with restrained warm-white typography.
- Strong typographic hierarchy and large negative space.
- Thin structural rules and numbered sections.
- Cards behave as project navigation, not decorative blocks.
- CTA hierarchy is explicit.
- Responsive behavior is designed for desktop, tablet and mobile.
- No runtime hooks or visual mutation layers.
- Project pages retain independent identity while using the shared system where appropriate.
