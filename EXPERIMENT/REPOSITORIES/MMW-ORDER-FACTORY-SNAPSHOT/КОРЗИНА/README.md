# КОРЗИНА — MMW-ORDER-FACTORY

Назначение: безопасное хранилище для версий, веток и материалов, которым временно не найдено применение или происхождение которых требует отдельной проверки.

## Правила

1. КОРЗИНА не является рабочей зоной.
2. Материалы в КОРЗИНЕ не используются проектами автоматически.
3. Ничего из КОРЗИНЫ не удаляется без отдельного решения.
4. Перемещение в КОРЗИНУ не означает, что материал признан плохим или окончательно ненужным.
5. Если материал снова понадобится, он восстанавливается из сохранённого источника/коммита.
6. Рабочие проекты, MMW-COMPANY, CONSERVED и FINAL не изменяются при помещении материала в КОРЗИНУ.
