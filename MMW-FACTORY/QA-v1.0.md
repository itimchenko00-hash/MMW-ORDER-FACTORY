# MMW FACTORY QA v1.1

G0 Scope — scope, exclusions, rollback and affected systems recorded; frozen states protected.
G1 Structure — stable ids, controlled data separation, valid mappings.
G2 Content — honest status, facts/assumptions/scenarios, no unsupported guarantees or internal terms.
G3 Media — existence, uniqueness, semantic mapping, project ownership, provenance.
G4 Interaction — runtime behavior, visible state, meaningful result, reversibility where intended, accessibility.
G5 Economics — units, derived outputs, propagation, visible missing data, scenario labels.
G6 Technical — syntax, startup, APIs, persistence, secrets, security/privacy/SEO.
G7 Commercial — first-screen clarity, intentional CTAs, project identity, mobile, privacy/contact.
G8 Production — approved commit parity, production behavior, logs, rollback and post-release verification.

Evidence rule: a gate is not passed by assumption.
