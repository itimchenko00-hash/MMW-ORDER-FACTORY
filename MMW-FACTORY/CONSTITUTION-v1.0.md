# MMW-COMPANY CONSTITUTION v1.1

- Truth before appearance.
- Evidence before readiness.
- Concepts are never presented as launched, proven or operating.
- Forecasts, scenarios and calculations are not guarantees.
- Economic results are traceable to explicit inputs and formulas.
- Facts, assumptions, scenarios and unknowns are distinguishable.
- Roles are never invented.
- Media supports the meaning of its content.
- Project identities remain distinct.
- Public pages use commercial language, not internal development jargon.
- User-facing controls must perform the function they communicate.
- Shared changes require impact review and regression.
- Production is never a testing laboratory.
- Every release is reproducible and rollbackable.
- Recurring defects become prevention mechanisms.

Release-blocking prohibited states include duplicate/mismatched media, dead interactions, duplicate primary controls, hidden economic assumptions, manual derived revenue, unsupported guarantees, stale competing data, production fallback storage, internal public terminology, cross-project contamination, frozen-state modification, release without gates/rollback, production/source drift, missing media provenance, missing privacy/consent for public data collection, and repeated manual fixes without prevention.
