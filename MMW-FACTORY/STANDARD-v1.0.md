# MMW-COMPANY STANDARD v1.1

Every project/page must have controlled identity, honest status, commercial content, project-specific visual identity, semantic media, functional interactions and traceable economics where applicable.

Media: asset → project → placement → semantic purpose; uniqueness where required; provenance for external assets.

Interaction: clear affordance → activated state → visible result → reversible/close where intended.

Economics: named inputs + units → deterministic derived outputs → visible missing-input behavior → labeled scenario; no guarantees.

Data: stable ids, valid mappings, controlled sources, no stale competing registries.

Public language: concise, commercial, understandable; no internal/debug/development jargon.

Technical: syntax, startup, persistence, validation, security, privacy and SEO controls are part of launch readiness.

Release: only approved, tested, rollbackable and verified artifacts may be promoted.
