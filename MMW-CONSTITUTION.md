# MMW-COMPANY / PROJECT CONSTITUTION

## 1. Architecture
- MMW-COMPANY is the master site and deployment space.
- Every project remains a distinct project inside the same master repository and service.
- ALADIN RESIDENCE is a project of MMW-COMPANY, not the company itself.

## 2. Replace, do not layer
- A content or media change replaces the corresponding existing element.
- Do not stack duplicate photos, infographics, cards, or sections to compensate for an earlier version.
- Each section must have one deliberate primary visual treatment: a semantic photograph OR a semantic infographic. Additional visuals are allowed only when they carry a clearly different functional role.

## 3. Media ownership
- Media must live in the repository before it is referenced by a page.
- ALADIN media belongs only to ASSETS/ALADIN/.
- MMW-COMPANY Factory media belongs to ASSETS/MMW-COMPANY/.
- ENERGY PARK media belongs to ASSETS/ENERGY-PARK/.
- Project media must not be silently mixed between project folders.

## 4. Semantic assignment
- Every photograph/infographic must correspond to the meaning of its block.
- Repeated aliases are not a substitute for semantic assignment.
- If a section is conceptual, process-oriented, economic, organizational, or risk-oriented, a matching infographic is preferred over a decorative photograph when available.

## 5. ALADIN
- Use the dedicated ALADIN visual library for ALADIN RESIDENCE.
- Dedicated infographics include: product architecture, market/audience, core flow, investment model, team ecosystem, risk control, and delivery roadmap.
- ALADIN remains explicitly a concept/demo project until verified project data exists.

## 6. Economics
- Do not invent financial inputs.
- Empty calculator fields remain empty.
- ROI, payback, break-even and project result are calculated only from user-provided parameters.
- The site must not present illustrative numbers as confirmed project economics.

## 7. Verification
- Frontend JavaScript must pass syntax validation.
- The ALADIN renderer must produce the full page, not only the site header.
- All referenced ALADIN infographic files must exist.
- A deployment is not considered finished until the Render deployment is live and the master URL is verified.
