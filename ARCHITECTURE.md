## Полный цикл MMW
IDEA → ASSET → CHECK → MODEL → DEAL → CONTROL → RESULT

## Принцип данных
Каждый публичный факт должен иметь понятный статус: фактический, планируемый или концептуальный. Неопределённые финансовые значения не подменяются выдуманными цифрами.

## Техническая схема
Render → Node.js → public/index.html + public/style.css + public/app.js.

Node.js слушает 0.0.0.0 и PORT. URL-маршруты без расширения возвращают index.html для клиентской навигации.

## Экономический контур — функциональное правило
Каждая проектная страница содержит интерактивную первичную экономическую форму. Пользователь вводит подтверждённые исходные данные: количество единиц, цену продажи, переменные затраты на единицу, годовую операционную выручку, годовой OPEX, общий CAPEX, долю инвестора и период расчёта. Система в браузере рассчитывает выручку продаж, результат продаж, годовой операционный результат, результат проекта за период, ROI, срок окупаемости, точку безубыточности в единицах и доход инвестора за период. Пустые исходные данные не заменяются выдуманными значениями. Расчёт является первичной моделью и не является инвестиционной гарантией.
