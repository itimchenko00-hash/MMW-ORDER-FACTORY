# OFFER CATALOG

Prices are initial commercial positioning in USD and must be confirmed in a proposal after scope diagnosis.

| Offer | Result | Initial price |
|---|---|---:|
| BUSINESS AUDIT | diagnostic, gaps, priorities | $300–700 |
| BUSINESS MODEL | customer/product/revenue/operations model | $700–1,500 |
| FINANCIAL MODEL | assumptions, unit economics, scenarios | $500–1,500 |
| INVESTMENT PACKAGE | investor narrative, economics, risks, data-room index | $1,000–3,000 |
| PROJECT DEVELOPMENT | complete business-project package | $3,000–8,000 |
| DEVELOPMENT PROJECT | complex project from idea to implementation package | $8,000–25,000+ |
| PROJECT ADAPTATION | adaptation of an existing MMW project to a client site | $1,500–7,500+ |
| READY-TO-SELL PROJECT | acquisition/licensing of a developed project package | typically $10,000–30,000+ |

## Entry product
The recommended first paid step is BUSINESS AUDIT. It creates a low-friction commercial entry and qualifies serious clients for larger work.

## Payment logic
- Audit: 100% before start.
- Larger packages: 50/50 or milestone billing.
- Project acquisition/licensing: separate agreement.
- Partnership/equity: separate term sheet and legal documentation.
