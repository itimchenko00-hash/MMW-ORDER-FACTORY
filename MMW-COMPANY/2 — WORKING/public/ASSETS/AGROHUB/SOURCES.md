## Runtime rule

The browser uses only local paths under /ASSETS/AGROHUB/photos/web-selected/.

No external image URL, remote runtime image, generated image, placeholder, CSS image proxy, or third-party image transformation is an active source.

## Integrity rule

The local binary is the deployed asset. If a future media change is required, import and verify a real source file first, record provenance, then run path, HTTP and visual QA before activation.
