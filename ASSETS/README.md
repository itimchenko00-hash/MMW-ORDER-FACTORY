# MMW-COMPANY — FACTORY ASSET LIBRARY

Permanent visual library for MMW-COMPANY and all projects.

## Rules
- Sites should reference `/assets/<PROJECT>/...` only.
- External image URLs are source material, not runtime dependencies.
- Free/licensed source metadata is kept in `ASSETS/_sources/`.
- Protected/conserved repositories and checkpoint branches are not modified by this library.
