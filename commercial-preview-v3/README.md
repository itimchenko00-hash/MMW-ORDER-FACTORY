# MMW-COMPANY Commercial 100% Mockup

Separate, noindex preview based on the current MMW-COMPANY/2 public pages and ORDER7 catalog/order-center interface.

- Preserves the current homepage, company page, detailed project catalog, six project pages, privacy page, and their existing interactions.
- Includes a second transactional catalog with 13 service formats and six project-development packages.
- Routes calls to action to a local-only order-center simulation. Demo requests and five-digit access codes are stored only in the visitor's browser. No production order API is called.
- Adds draft commercial terms and intellectual-product rights pages; both require legal/business approval before real publication.
- Images load from existing live MMW-COMPANY/2 asset URLs for preview only.
- Keep on the separate branch and separate Render static site. Do not merge into production without a separate release decision.
