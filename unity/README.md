# ЕДИНСТВО — продукт и правила разработки

ЕДИНСТВО — самостоятельный социальный продукт. Текущая опубликованная версия является презентационной страницей; она не заявляет о наличии функций, которые ещё не реализованы.

## Принцип развития
Идея → продуктовые требования → архитектура → реализация → автоматические проверки → приёмка → публикация → мониторинг → обслуживание → развитие.

## Текущий статус
- Презентационная страница: опубликована на Render.
- Регистрация, профили, публикации, лента, комментарии, реакции, друзья, сообщения и уведомления: ещё не реализованы.
- Рабочая база данных и серверный API: не подключены.
- Мобильное приложение: будущий этап после веб-MVP.

## Границы проекта
- Проект размещается в каталоге `unity/` существующего репозитория и публикуется отдельным Render-сайтом.
- Не изменять основной production-сайт MMW-COMPANY, его коммерческий контур и клиентские профили.
- Не подключать платные сервисы, новую базу данных или внешнюю инфраструктуру без отдельного согласования.
- Не помещать секреты, ключи, пароли или реальные персональные данные в репозиторий.
- Не объявлять функцию готовой до реализации и проверки.

## Принцип следующего этапа
Сначала утвердить архитектуру и ограничения, затем подготовить рабочую среду и CI, после этого реализовать MVP вертикальными сценариями — от интерфейса до проверенного сохранения данных.
