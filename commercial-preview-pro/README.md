# MMW-COMPANY — Commercial Pro mockup
Separate commercial information architecture for evaluation only.

## Purpose
This version professionally integrates the company's positioning into a clear customer journey:
1. Main promise and four entry paths.
2. Existing six project concepts.
3. Individual project development.
4. Help with complex business situations.
5. Professional service catalogue.
6. Intellectual products and contract-dependent rights models.
7. Working approach, customer groups, principles and inquiry form.

## Preserved pages
This directory includes copies of the prior mockup's company/about page, original catalog, commercial service catalog, demo order center, terms draft, IP rights draft, privacy page and all six project pages. `company-home-original.html` preserves the previous commercial mockup homepage content. This homepage is a new editorial/UX structure, not a replacement of production.

## Safety boundary
- This is a separate branch and separate Render static-site deployment.
- Do not merge or deploy this branch to the production `mmw-company-2` service.
- The homepage inquiry form only opens a mail draft; it does not send to a server or save data.
- The order-center page is a browser-local demonstration and does not submit orders to production.
- Commercial terms are drafts for business/legal review, not final legal advice.
- Project pages describe concepts; they do not assert construction, launch, funding, permits or achieved commercial results.
- Project imagery on copied project pages may reference the live MMW-COMPANY/2 asset host for preview display only. No production files or data are changed by this mockup.
