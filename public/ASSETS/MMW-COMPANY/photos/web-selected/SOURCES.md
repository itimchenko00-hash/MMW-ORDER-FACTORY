## Selection rule

Images were selected by semantic meaning, not by generic decoration. Each project receives a distinct subject and no image is intentionally reused between project cards.

## Import gate

The selected sources must be downloaded into the local Factory asset folder, renamed deterministically, provenance recorded, and only then inserted into production markup.

External runtime URLs are prohibited.
