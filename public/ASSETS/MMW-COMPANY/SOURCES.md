# MMW-COMPANY — media provenance

The company presentation uses the local media set referenced by `public/app.js`. The active runtime path is `/ASSETS/MMW-COMPANY/photos/`.

The filenames preserve the original Unsplash photo identifiers. Source pages were used only as controlled web sources during selection; they are not runtime dependencies. The repository retains the original media set under the legacy source location while the active runtime exposes it through the local asset root.

Runtime rule: no external image URL is used for presentation media.
